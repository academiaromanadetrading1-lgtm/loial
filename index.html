Google Translate API – Live Example

Campaign text is sent to the Translation API and returned in the target language. In production the key stays on the server.

POST https://translation.googleapis.com/language/translate/v2
{
  "q": "Hi Andrei, we noticed you love cappuccinos...",
  "target": "ro",
  "source": "en",
  "format": "text"
}

Response:
{
  "data": {
    "translations": [{
      "translatedText": "Bună Andrei, am observat că iubești cappuccino..."
    }]
  }
}

The demo uses the public endpoint for instant translation. Production uses the official Cloud Translation API with a server-side key.

Backend examples for translating campaigns, sending Wallet updates and logging events with Google APIs.

Google Translate + Campaign Generator (Python)

from google.cloud import translate_v2 as translate
import openai  # or your AI provider

translate_client = translate.Client()

def generate_and_translate(customer_name, preference, target_lang="ro"):
    prompt = f"Write a short loyalty offer for {customer_name} who loves {preference}."
    offer_en = openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}]
    ).choices[0].message.content

    result = translate_client.translate(offer_en, target_language=target_lang)
    return result["translatedText"]

print(generate_and_translate("Andrei", "cappuccino", "ro"))
